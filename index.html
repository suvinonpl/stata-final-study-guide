🧪 ตารางเช็ค Assumption & Diagnostics ครบชุด

กฎการเช็คสุขภาพข้อมูลก่อนเชื่อผลลัพธ์ — จำง่าย: พวกทดสอบ Assumption ส่วนใหญ่ "อยากได้ $p \ge 0.05$" (แปลว่าผ่านเกณฑ์!)

สถิติที่ใช้ Assumption ที่ต้องเช็ค คำสั่ง STATA เกณฑ์ "ผ่าน" ✅ ถ้า "ตกเกณฑ์" ❌ ต้องทำอะไร?
t-test / ANOVA Normality (แจกแจงปกติ) swilk y หรือ sktest y $p \ge 0.05$ (และดู Histogram/Boxplot) ใช้ ranksum (2 กลุ่ม), signrank (คู่), kwallis (≥3 กลุ่ม)
2-sample t-test Equal variances (SD 2 กลุ่มเท่ากัน) sdtest y, by(x) $p \ge 0.05$ → ใช้ t-test ปกติ $p < 0.05$ → เติม , unequal (Welch's t-test)

Chi-square ($\chi^2$) Expected count ในแต่ละช่อง tab x y, expected 2×2: ทุกช่อง $E \ge 5$
$R\times C$: ช่องที่ $E<5$ ไม่เกิน 20% และไม่มีช่อง $E<1$		 อ่านค่า Fisher's exact (, exact) แทน Pearson chi2
Linear Regression L-I-N-E & Multicollinearity rvfplot, estat hettest, predict r, resid → swilk r, vif • Homoscedasticity: hettest $p \ge 0.05$
• Normality of residuals: swilk r $p \ge 0.05$
• No collinearity: VIF < 10		 ใช้ , vce(robust) หรือ Transform $Y$ / ตัดตัวแปรที่ซ้ำซ้อนออก
Logistic Regression Goodness-of-Fit & Discrimination estat gof, group(10) (Hosmer-Lemeshow)
lroc (AUC)		 • H-L test: $p \ge 0.05$ (โมเดลฟิตดี!)
• AUC $\ge 0.70$ (จำแนกได้ดี)		 เพิ่ม Interaction / ปรับรูปตัวแปรต่อเนื่อง / ตรวจสอบ Outlier
⚠️ ข้อควรระวังยอดฮิตในห้องสอบ:
  • Bartlett's test / Shapiro-Wilk / Breusch-Pagan (hettest) / Hosmer-Lemeshow (gof): ทั้งหมดนี้ $p \ge 0.05$ คือ "ดี / ผ่านเกณฑ์" (ไม่ปฏิเสธ $H_0$ ที่ว่าปกติ / ความแปรปรวนเท่ากัน / โมเดลฟิตดี)
  • Linear Regression: ต้องเช็ค Normality ที่ Residuals ($e = Y - \hat{Y}$) ไม่ใช่เช็คแค่ตัวแปร $Y$ ดิบๆ!

🎯 จุดจ้องดู p-value, กฎ 95% CI (คร่อม 0 vs คร่อม 1) และ RR vs OR

1) 95% CI คร่อม 0 → ใช้กับ "ผลต่าง" (Difference)

มาจากการ ลบกัน ($A - B$): Mean Diff, Risk Diff (RD), ค่า $\beta$ ใน Linear Regression

  • Null value ($H_0$): $= \mathbf{0}$
  • คร่อม 0 (เช่น $[-0.0026, +0.0041]$) → ไม่ซิก ($p \ge 0.05$)
  • ไม่คร่อม 0 (บวกทั้งคู่ หรือ ลบทั้งคู่) → ซิก ($p < 0.05$)

2) 95% CI คร่อม 1 → ใช้กับ "อัตราส่วน" (Ratio)

มาจากการ หารกัน ($A / B$): Odds Ratio (OR), Risk Ratio (RR), IRR, Hazard Ratio (HR)

  • Null value ($H_0$): $= \mathbf{1}$
  • คร่อม 1 (เช่น $[0.45, 1.12]$) → ไม่ซิก ($p \ge 0.05$)
  • ไม่คร่อม 1 ($>1$ ทั้งคู่ = ปัจจัยเสี่ยง, $<1$ ทั้งคู่ = ปัจจัยป้องกัน) → ซิก ($p < 0.05$)

จุดจ้องดู p-value ใน Output ของ STATA ทุกคำสั่ง

คำสั่ง STATA ค่าสถิติที่รายงาน จุดที่ต้องจ้องดู p-value หมายเหตุสำคัญ
ttest y, by(x) $t$ (Mean diff) Pr(|T| > |t|) (คอลัมน์กลาง = Two-sided) ดูทิศทาง diff = mean(0) - mean(1) ให้ดีว่าใครตั้งลบใคร!
ranksum y, by(x) $z$ (Mann-Whitney) Prob > |z| รายงาน Median (IQR) ด้วยคำสั่ง tabstat y, by(x) s(p50 p25 p75)
signrank x1 = x2 $z$ (Wilcoxon) Prob > |z| สำหรับ 2 กลุ่มจับคู่ (Nonparametric)
oneway y x, bonf $F$ (ANOVA) Prob > F (ภาพรวม) + ตารางล่าง (รายคู่) เช็ค Bartlett's Prob>chi2 ด้านล่างก่อนเสมอ!
kwallis y, by(x) $\chi^2$ (Kruskal-Wallis) probability with ties (ใช้บรรทัด with ties เสมอ) ข้อมูลคะแนน/ซ้ำกันเยอะต้องอ่าน with ties
tab x y, chi2 exact Pearson $\chi^2$ Pr = ... (หรือ Fisher's exact ถ้า $E<5$) ใส่ row หรือ col เพื่อดูความชุก (%)
mcc / mcci McNemar's $\chi^2$ Prob > chi2 (หรือ Exact McNemar ถ้า $b+c<25$) ดูเฉพาะช่องที่ไม่ตรงกัน (Discordant pairs $b, c$)
reg y x1 x2 $F$ (โมเดล), $t$ (รายตัว) Prob > F (ภาพรวม), P>|t| (แต่ละตัวแปร) ดู Coef. และ [95% Conf. Interval] (เช็คคร่อม 0)
logistic y x1 x2 LR $\chi^2$, $z$ (Wald) Prob > chi2 (ภาพรวม), P>|z| (แต่ละตัวแปร) แสดงเป็น Odds Ratio ทันที (เช็คคร่อม 1)

⚖️ บทที่ 1: Two-Sample Continuous, Binomial & Nonparametric (L6-1, L6-2, Nonparametric)

Continuous 2 กลุ่ม (Parametric vs Nonparametric)

  • 2 กลุ่มอิสระ (ปกติ): Independent t-test → เช็ค sdtest ก่อน ถ้า SD ไม่เท่ากันให้เติม , unequal (Welch's t-test)
  • 2 กลุ่มอิสระ (เบ้/Ordinal): Mann-Whitney U test (ranksum)
  • 2 กลุ่มจับคู่ (ก่อน-หลัง, ปกติ): Paired t-test (ttest x1 == x2) — เช็ค normality ของ ผลต่าง ($d = x_1 - x_2$)
  • 2 กลุ่มจับคู่ (ก่อน-หลัง, เบ้): Wilcoxon signed-rank test (signrank)

Binomial & Proportion Tests (L6-2)

  • 1 กลุ่ม เทียบสัดส่วน $p_0$:
    • ตัวอย่างใหญ่ ($np_0 \ge 5$ และ $n(1-p_0) \ge 5$): prtest / prtesti (z-test)
    • ตัวอย่างเล็ก: bitest / bitesti (Exact Binomial)
  • 2 กลุ่มอิสระ เทียบสัดส่วน ($p_1$ vs $p_2$):
    • prtest y, by(group) หรือ prtesti n1 p1 n2 p2
    • หมายเหตุ: Two-sample z-test for proportions ให้ค่า $z^2 = \chi^2$ และ $p$-value เท่ากับ Chi-square 2×2 เป๊ะ!
STATA Commands: Two-Sample Continuous, Nonparametric & Proportions
* 1. ตรวจสอบ Normality & Equal Variance
swilk bwt
sdtest bwt, by(smoke)

* 2. Independent & Paired t-test (Parametric)
ttest bwt, by(smoke)                // Equal variance
ttest bwt, by(smoke) unequal        // Welch's t-test (เมื่อ sdtest p < 0.05)
ttest fuhip == basehip               // Paired t-test (ก่อน-หลัง ในคนเดียวกัน)
ttesti 30 120 15 30 110 12          // Immediate (n1 m1 sd1 n2 m2 sd2)

* 3. Nonparametric 2 กลุ่ม (รายงาน Median, IQR)
tabstat bwt, by(smoke) stat(n p50 p25 p75)
ranksum bwt, by(smoke)              // Mann-Whitney U test (2 กลุ่มอิสระ)
signrank fuhip = basehip             // Wilcoxon signed-rank test (จับคู่)

* 4. Binomial & Proportion Test
bitesti 20 14 0.5                    // Exact binomial (n=20, observed=14, p0=0.5)
prtest lbw, by(smoke)               // 2-sample proportion z-test
prtesti 74 30 115 29, count         // Immediate 2-sample proportion (ใส่ count)

📑 บทที่ 2: Categorical Outcomes, Matched/Paired & Tables for Epidemiologists

ครอบคลุม L9 Categorical Outcomes, L10 Matched/Paired Analysis, Measure of Association (RR/OR), 2024 Tables for Epidemiologists

1) Chi-square ($\chi^2$) & Fisher's Exact

$$\chi^2 = \sum \frac{(O - E)^2}{E}, \quad E = \frac{\text{Row} \times \text{Col}}{\text{Total}}$$

$df = (r-1)(c-1)$
ค่าวิกฤตที่ $\alpha=0.05$: $df=1 \to \mathbf{3.841}$, $df=2 \to \mathbf{5.991}$
ถ้าช่อง 2×2 มี $E < 5$ → ใช้ Fisher's exact

2) Matched / Paired (McNemar's Test)

$$\text{OR}_{\text{matched}} = \frac{b}{c}, \quad \chi^2_{\text{McNemar}} = \frac{(b - c)^2}{b + c}$$

ใช้เฉพาะ Discordant pairs ($b, c$) (คู่ที่ผลต่างกัน)
ถ้า $b+c < 25$ → ดูค่า Exact McNemar p-value
STATA: mcc case_exp ctrl_exp / mcci a b c d

3) Measure of Association (2×2)

  • Cohort / RCT (`cs`):
    $\text{RR} = \frac{a/(a+b)}{c/(c+d)}$, $\text{RD} = R_1 - R_0$
  • Case-Control (`cc`):
    $\text{OR} = \frac{a \times d}{b \times c}$ (ใช้แทน RR ได้เมื่อโรคหายาก <10%)
  • Person-Time (`ir`):
    $\text{IRR} = \frac{a / PT_1}{b / PT_0}$
  • Attributable Fraction:
    $AF_e = \frac{RR-1}{RR}$ (หรือ $\frac{OR-1}{OR}$)

Mantel-Haenszel Stratified Analysis: แยก Confounding vs. Effect Modification

เมื่อสั่ง cc y x, by(z) หรือ cs y x, by(z) เพื่อแบ่งชั้นตามตัวแปรที่ 3 ($z$ เช่น แยกตาม smoke):
  1. ดู Test of homogeneity (Breslow-Day / M-H) ก่อนเสมอ!
    • ถ้า $p < 0.05$ → ค่า OR ในแต่ละชั้น ไม่เท่ากัน = เกิด Effect Modification (Interaction) → ห้ามรวมเป็นค่าเดียว! ต้องรายงานแยกแต่ละชั้น (Stratum-specific OR)
    • ถ้า $p \ge 0.05$ → ค่า OR ในแต่ละชั้นใกล้เคียงกัน (ไม่มี Interaction) → ขยับไปเช็ค Confounding ข้อ 2
  2. เช็ค Confounding (กฎ 10%): เทียบ Crude OR กับ M-H Combined OR (Adjusted OR)
    • ถ้า $\left|\frac{\text{Crude OR} - \text{Adjusted OR}}{\text{Adjusted OR}}\right| \ge 10\%$ → ตัวแปร $z$ เป็น Confounder ให้รายงานค่า M-H Adjusted OR

* 2. Cohort Study (Risk Ratio, Risk Difference, AFe, AFp)

csi 30 29 44 86                                  // Immediate (a=ExpCase, b=UnexpCase, c=ExpNon, d=UnexpNon)

* 3. Case-Control Study (Odds Ratio, AFe, AFp) & Stratified Mantel-Haenszel

cc lbw smoke, by(race)                          // Stratified OR + M-H Adjusted OR + Test of Homogeneity

* 4. Incidence Rate (Person-Time) & Matched Case-Control (McNemar)

mcc case_exp ctrl_exp                            // Matched pair (1 แถว = 1 คู่)

📊 บทที่ 3: Comparing Multiple Samples (≥ 3 กลุ่ม) — ANOVA & Kruskal-Wallis

ครอบคลุม L11 Comparing Multiple Samples & 2026-10 ANOVA

โครงสร้างตาราง ANOVA (F-test)

$$F = \frac{MS_{\text{between}}}{MS_{\text{within}}} = \frac{SS_B / (k-1)}{SS_W / (N-k)}$$
  • ทำไมค่า F เบ้ขวาเสมอ? เพราะเป็นอัตราส่วนของผลรวมกำลังสอง ($F \ge 0$ ติดลบไม่ได้), ใต้ $H_0$ ค่า $F \approx 1$, บริเวณปฏิเสธอยู่ หางขวาเท่านั้น
  • ถ้ามี 2 กลุ่ม: One-way ANOVA ให้ค่า $F = t^2$ และ $p$-value เท่ากับ Independent t-test (two-tailed) เป๊ะ!
  • ข้อตกลง: เช็ค Bartlett's test ด้านล่างตาราง ต้องได้ $p \ge 0.05$

Post-hoc Multiple Comparisons (เมื่อ ANOVA $p < 0.05$)

  • ANOVA ตอบได้แค่ว่า "มีอย่างน้อย 1 คู่ที่ต่างกัน" แต่ไม่บอกว่าคู่ไหน
  • Bonferroni correction: ป้องกัน Family-wise Type I error ($1 - (1-\alpha)^c$)
    $$c = \frac{k(k-1)}{2}, \quad \alpha^* = \frac{\alpha}{c}$$
    เช่น 3 กลุ่ม $\to 3$ คู่ ($\alpha^* = 0.0167$); 4 กลุ่ม $\to 6$ คู่ ($\alpha^* = 0.0083$)
  • ใน STATA: ค่า $p$-value ในตาราง Bonferroni ถูกคูณ $c$ มาให้แล้ว อ่านเทียบ $0.05$ ได้เลย!
STATA Commands: One-way ANOVA, Post-hoc & Kruskal-Wallis
* 1. One-way ANOVA + ตารางค่าเฉลี่ย + Bonferroni Post-hoc + Bartlett's test

* 2. เช็ค Equal Variance ด้วย Levene's test (ทนต่อข้อมูลเบ้ดีกว่า Bartlett)
robvar bwt, by(race)                            // ดูค่า W0 (Levene) หรือ W50 (Brown-Forsythe)

* 3. Pairwise comparisons พร้อม 95% CI ของผลต่างรายคู่
pwmean bwt, over(race) mcompare(bonferroni) effects

* 4. Nonparametric ≥3 กลุ่ม (เมื่อข้อมูลเบ้มาก / Ordinal / Bartlett p < 0.05)

kwallis bwt, by(race)                           // อ่าน probability with ties

📐 บทที่ 4: Sample Size Calculation & Power (L12)

สูตรคำนวณมือออกสอบทุกปี + คำสั่ง STATA power ครบทั้ง Estimation (1 กลุ่ม) และ Hypothesis Testing (2 กลุ่ม)

📌 ค่า Z ที่ต้องจำให้แม่น (ใช้คำนวณมือ):
• Two-sided $\alpha = 0.05 \implies \mathbf{Z_{1-\alpha/2} = 1.96}$  |  $\alpha = 0.01 \implies \mathbf{Z_{1-\alpha/2} = 2.576}$
• Power $80\%$ ($\beta = 0.20$) $\implies \mathbf{Z_{1-\beta} = 0.84}$  |  Power $90\%$ ($\beta = 0.10$) $\implies \mathbf{Z_{1-\beta} = 1.28}$
• กฎปัดเศษ: Sample size ต้อง ปัดขึ้น (Round UP) เสมอ (เช่น $311.17 \to \mathbf{312}$)
สถานการณ์ / วัตถุประสงค์ สูตรคำนวณมือ คำสั่ง STATA
1. ประมาณค่าเฉลี่ย 1 กลุ่ม
(Estimating 1 Mean)		 $$n = \frac{Z_{1-\alpha/2}^2 \cdot \sigma^2}{d^2}$$ sampsi m0 m1, sd(#) power(0.5) onesample
2. ประมาณค่าสัดส่วน 1 กลุ่ม
(Estimating 1 Proportion)		 $$n = \frac{Z_{1-\alpha/2}^2 \cdot p(1-p)}{d^2}$$
(ถ้าไม่ทราบ $p$ ใช้ $p = 0.5$)		 sampsi p0 p1, power(0.5) onesample
3. เปรียบเทียบค่าเฉลี่ย 2 กลุ่มอิสระ
(Two independent means, $n$ ต่อกลุ่ม)		 $$n = \frac{2\sigma^2 (Z_{1-\alpha/2} + Z_{1-\beta})^2}{(\mu_1 - \mu_2)^2}$$ power twomeans m1 m2, sd(#) power(0.8)
4. เปรียบเทียบสัดส่วน 2 กลุ่มอิสระ
(Cohort / Case-Control, $n$ ต่อกลุ่ม)		 $$n = \frac{\left[Z_{1-\alpha/2}\sqrt{2\bar{p}(1-\bar{p})} + Z_{1-\beta}\sqrt{p_1(1-p_1)+p_2(1-p_2)}\right]^2}{(p_1 - p_2)^2}$$
โดย $\bar{p} = \frac{p_1 + p_2}{2}$; Cohort: $p_1 = RR \times p_2$; Case-Control: $p_1 = \frac{OR \cdot p_2}{1 + p_2(OR-1)}$		 power twoproportions p1 p2, test(chi2) power(0.9)
power twoproportions p2, rrisk(#) power(0.9)
power twoproportions p2, oratio(#) power(0.9)
5. เปรียบเทียบค่าเฉลี่ยจับคู่
(Paired / Dependent samples)		 $$n = \frac{S_d^2 (Z_{1-\alpha/2} + Z_{1-\beta})^2}{(\mu_1 - \mu_2)^2}$$ power pairedmeans m1 m2, sddiff(#) power(0.8)
🚨 กับดัก Non-response / Drop-out (ออกสอบบ่อยมาก!):
ถ้าเผื่อ Non-response 10% ($r = 0.10$) ต้องใช้สูตรหาร: $$n_{\text{final}} = \frac{n}{1 - r} = \frac{312}{1 - 0.10} = \frac{312}{0.90} = 346.67 \to \mathbf{347}$$ ❌ ห้ามเอา $n \times 1.10$ เด็ดขาด!
💡 กฎการเปลี่ยน Precision ($d$):
เนื่องจาก $n \propto \frac{1}{d^2}$ หากต้องการความแม่นยำเพิ่มขึ้น 2 เท่า (ลด margin of error ลงครึ่งหนึ่ง เช่น $\pm 100 \to \pm 50$):
ขนาดตัวอย่าง $n$ จะเพิ่มขึ้นเป็น $2^2 = \mathbf{4 \text{ เท่า}}$ เสมอ!

📈 บทที่ 5: Correlation, Simple & Multiple Linear Regression (L13, L14, 2025 Correlation, Stata 3 Nov)

Correlation ($r$ vs $\rho$)

  • Pearson ($r$): Continuous ทั้งคู่, เส้นตรง, ปกติ, ไม่มี Outlier
  • Spearman ($\rho$): เบ้มาก, มี Outlier, หรือเป็น Ordinal
  • เกณฑ์ขนาด $|r|$: $0.10-0.29$ ต่ำ, $0.30-0.49$ ปานกลาง, $0.50-0.69$ สูง, $\ge 0.70$ สูงมาก, $\ge 0.90$ เกือบสมบูรณ์
  • Coefficient of Determination ($R^2 = r^2$): เช่น $r = 0.60 \implies R^2 = 0.36$ (อธิบายความผันแปรได้ 36%)
  • ⚠️ จำไว้: Correlation บอกแค่ความสัมพันธ์ (Association) ไม่ใช่ เหตุและผล (Causation)!

Multiple Linear Regression & Dummy Variables

  • สมการ: $Y = \beta_0 + \beta_1 X_1 + \beta_2 X_2 + \dots + \varepsilon$
  • กฎ Dummy: ตัวแปรกลุ่มมี $k$ ระดับ $\to$ สร้าง $k - 1$ ตัวแปรดัมมี่ (เว้น 1 กลุ่มเป็น Reference)
  • ใน STATA: ใส่ i.race (อ้างอิงกลุ่มแรก) หรือ ib2.race (เปลี่ยนกลุ่มอ้างอิงเป็นกลุ่ม 2)
  • สมมติฐานใน Regression (3 กลุ่ม):
    $H_0: \beta_1 = \beta_2 = 0$
    $H_a:$ มีอย่างน้อยหนึ่งค่า $\beta_j \neq 0$
  • $R^2$ vs Adjusted $R^2$: ใช้ Adj $R^2$ เปรียบเทียบโมเดลที่มีจำนวนตัวแปรต่างกัน

🧬 บทที่ 6: Simple & Multiple Logistic Regression (Binary Outcome: 0/1)

ครอบคลุม Multiple_Logistic_Stat1_Nov5-2026 & 3. Linear and Logistic Regression

สมการ Logit, AOR และ Predicted Probability ($\hat{P}$)

$$\text{logit}(P) = \ln\!\left(\frac{P}{1-P}\right) = \beta_0 + \beta_1 X_1 + \dots + \beta_k X_k = z$$
  • แปลง $\beta$ เป็น AOR (ต่อ 1 หน่วย): $\text{AOR} = e^{\beta}$ (เช่น $e^{0.693} = 2.00$)
  • แปลง $\beta$ เป็น AOR เมื่อเพิ่ม $\Delta X$ หน่วย: $\text{AOR}_{\Delta X} = e^{\beta \times \Delta X}$
    (เช่น BMI เพิ่ม 5 หน่วย, $\beta = 0.120 \implies e^{0.120 \times 5} = e^{0.60} \approx \mathbf{1.82}$)
  • คำนวณความน่าจะเป็น (Predicted Probability):
    $$P = \frac{1}{1 + e^{-z}} = \frac{e^z}{1 + e^z}$$

Model Building & Diagnostics (รศ.สมรัตน์)

  • Univariate Screening (Hosmer-Lemeshow): คัดตัวแปรที่ $p < 0.25$ หรือมีความสำคัญทางชีววิทยาเข้า Multivariable model
  • logit vs logistic:
    • logit แสดงเป็น $\beta$ (Log-odds) — ใช้เขียนสมการ & คำนวณ $z$
    • logistic แสดงเป็น Odds Ratio (AOR) ทันที
  • เทียบ 2 โมเดล (Nested models): ใช้ Likelihood Ratio Test (lrtest)
  • Goodness-of-Fit: estat gof, group(10) (Hosmer-Lemeshow) → $p \ge 0.05$ = โมเดลฟิตดี
  • Classification & ROC: estat classification (Sens/Spec/Accuracy) และ lroc (AUC)
🧮 ตัวอย่างคำนวณความน่าจะเป็น ($\hat{P}$) ออกสอบอัตนัย (ข้อสอบจำลองข้อ 3.5):
สมการ: $z = -8.100 + 0.045(\text{age}) + 0.120(\text{bmi}) + 0.250(\text{male}) + 0.920(\text{famhx})$
โจทย์: ผู้หญิง ($\text{male}=0$) อายุ $50$ ปี, $\text{BMI}=30$, มีประวัติครอบครัว ($\text{famhx}=1$)
1) $z = -8.100 + 0.045(50) + 0.120(30) + 0.250(0) + 0.920(1) = -8.100 + 2.25 + 3.60 + 0.92 = \mathbf{-1.330}$
2) $P = \frac{1}{1 + e^{-(-1.330)}} = \frac{1}{1 + e^{1.330}} = \frac{1}{1 + 3.781} = \mathbf{0.209}$ (หรือ 20.9%)
STATA Commands: Logistic Regression, LRT, Goodness-of-Fit & ROC
* 1. รัน Logistic Regression (แสดง OR vs แสดง Coef)
logistic lbw ib2.race smoke age wt_lmp hyper urirr   // แสดง AOR ทันที
logit    lbw ib2.race smoke age wt_lmp hyper urirr   // แสดง Coef (β) สำหรับเขียนสมการ

* 2. Likelihood Ratio Test (เปรียบเทียบ Full model vs Reduced model)
logit lbw i.race smoke age wt_lmp hyper urirr
estimates store full
logit lbw i.race smoke wt_lmp hyper urirr            // ตัด age ออก
estimates store reduced
lrtest full reduced                                  // ถ้า p >= 0.05 ตัด age ออกได้

* 3. Goodness-of-Fit, Classification Table & ROC Curve
estat gof, group(10)                                 // Hosmer-Lemeshow (p >= 0.05 = ฟิตดี)
estat classification                                  // Sensitivity, Specificity, Accuracy
lroc                                                  // Area Under ROC Curve (AUC)

📋 คลังประโยคแปลผลพร้อมก๊อป & Checklist 30 วินาทีก่อนส่งข้อสอบ

1. ประโยคแปลผล Multiple Linear Regression (Categorical & Continuous)
เมื่อควบคุมปัจจัยอื่นๆ ในแบบจำลองให้คงที่ (Adjusted for ...): (1) กลุ่ม [X=1] มีค่าเฉลี่ยของ [Y] [สูงกว่า/ต่ำกว่า] กลุ่มอ้างอิง [X=0] อยู่ [|β|] [หน่วย] อย่างมีนัยสำคัญทางสถิติ (95% CI: [L] ถึง [U], p = [...]); (2) ทุกๆ 1 [หน่วย] ที่เพิ่มขึ้นของ [X_cont] สัมพันธ์กับค่า [Y] ที่ [เพิ่มขึ้น/ลดลง] เฉลี่ย [|β|] [หน่วย] อย่างมีนัยสำคัญทางสถิติ (95% CI: [L] ถึง [U], p = [...])
2. ประโยคแปลผล Multiple Logistic Regression (AOR — Categorical & Continuous)
เมื่อควบคุมปัจจัยอื่นๆ ในแบบจำลองให้คงที่: (1) ผู้ที่มีปัจจัย [X=1] มีโอกาส (Odds) ในการเกิด [Outcome] เป็น [AOR] เท่า ของผู้ที่ไม่มีปัจจัย [X=0] อย่างมีนัยสำคัญทางสถิติ (95% CI: [L] ถึง [U], p = [...]); (2) ทุกๆ [1 หรือ ΔX] [หน่วย] ที่เพิ่มขึ้นของ [X_cont] ทำให้โอกาส (Odds) ในการเกิด [Outcome] เปลี่ยนไปเป็น [AOR] เท่า (หรือ [เพิ่มขึ้น/ลดลง] [|AOR-1|×100]%) อย่างมีนัยสำคัญทางสถิติ (95% CI: [L] ถึง [U], p = [...])
3. ประโยคแปลผล One-way ANOVA + Bartlett's + Bonferroni
จากการทดสอบ Bartlett's test พบว่าความแปรปรวนของทุกกลุ่มไม่แตกต่างกัน (p = [...] ≥ 0.05) ผ่านข้อตกลงของ One-way ANOVA ผลการวิเคราะห์พบว่าค่าเฉลี่ยของ [Y] ระหว่างกลุ่ม [X] มีความแตกต่างกันอย่างมีนัยสำคัญทางสถิติ (F([df1], [df2]) = [...], p = [...]) เมื่อเปรียบเทียบรายคู่ด้วยวิธี Bonferroni พบว่ากลุ่ม [A] แตกต่างจากกลุ่ม [B] อย่างมีนัยสำคัญ (mean diff = [...], p = [...])

  • ✅ เช็คตัวแปรตาม (Y) ก่อนเลือกคำสั่ง: Continuous $\to$ reg | Binary (0/1) $\to$ logistic / logit (อย่าสลับ!)
  • ✅ ตัวแปรกลุ่ม ≥3 กลุ่มใน Regression: ใส่ i. (หรือ ib#.) แล้วหรือยัง? (จำนวน dummy = $k-1$)
  • ✅ 95% CI: ผลต่าง ($\beta$, Mean diff, RD) เช็ค คร่อม 0 | อัตราส่วน (OR, RR, IRR) เช็ค คร่อม 1
  • ✅ คำว่า "เมื่อควบคุมปัจจัยอื่นๆ ให้คงที่": ใน Multiple Regression ห้ามลืมเขียนคำนี้เด็ดขาด!
  • ✅ Non-response Adjustment: ใช้ $n / (1 - r)$ และปัดขึ้นเป็นจำนวนเต็มเสมอ!
