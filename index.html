🎯 จุดจ้องดู p-value, กฎ 95% CI (คร่อม 0 vs คร่อม 1) และ RR vs OR

95% CI คร่อม 0 → สถิติแบบ "ผลต่าง" (Difference)

มาจากการ ลบกัน ($A - B$): Mean Diff, Risk Diff (RD), ค่า $\beta$ ใน Linear Regression

  • Null value ($H_0$): $= \mathbf{0}$
  • คร่อม 0 (ลบถึงบวก เช่น $[-22.24, +15.97]$) → ไม่ซิก ($p \ge 0.05$)
  • ไม่คร่อม 0 (บวกทั้งคู่ หรือ ลบทั้งคู่) → ซิก ($p < 0.05$)

95% CI คร่อม 1 → สถิติแบบ "อัตราส่วน" (Ratio)

มาจากการ หารกัน ($A / B$): OR, RR, IRR, HR

  • Null value ($H_0$): $= \mathbf{1}$
  • คร่อม 1 (เช่น $[0.45, 1.12]$) → ไม่ซิก ($p \ge 0.05$)
  • $>1$ ทั้งคู่: ปัจจัยเสี่ยง (Risk factor, ซิก)
  • $<1$ ทั้งคู่: ปัจจัยป้องกัน (Protective factor, ซิก)

⚖️ บทที่ 1: Two-Sample Continuous, Binomial, Poisson & Nonparametric

สรุปละเอียดจาก L6-1 (รศ.นพ.ธนันท์), L6-2 Binomial & Sign Test, และ 2025 Nonparametric Statistics (ผศ.ดร.นพ.ธนภูมิ)

1.1 Two-Sample Comparison of Continuous Data (L6-1)

เมื่อต้องการเปรียบเทียบค่าเฉลี่ยของตัวแปรต่อเนื่องระหว่าง 2 กลุ่มอิสระ ($X_1,\dots,X_n$ vs $Y_1,\dots,Y_m$) ให้เดินตาม 3 ขั้นตอนมาตรฐานในสไลด์:

  1. Step 1 — ตรวจ Normality: ข้อมูลแจกแจงปกติหรือไม่ (หรือ $n$ ใหญ่พอใช้ Central Limit Theorem)? ถ้า ไม่ปกติ → ไป Nonparametric (ranksum)
  2. Step 2 — ตรวจ Equal Variances ด้วย F-test (`sdtest`): ตั้งสมมติฐาน $H_0: \frac{s_x^2}{s_y^2} = 1$ (SD ทั้ง 2 กลุ่มเท่ากัน)
    • ถ้า sdtest ได้ $p \ge 0.05$ → ความแปรปรวนเท่ากัน ใช้ Pooled-Variance t-test
    • ถ้า sdtest ได้ $p < 0.05$ → ความแปรปรวนไม่เท่ากัน ใช้ Unequal-Variance (Welch's) t-test (เติม , unequal)
  3. Step 3 — คำนวณ t-statistic และ 95% CI:
    $$s_p^2 = \frac{(n-1)s_x^2 + (m-1)s_y^2}{n+m-2}, \qquad t_{df = n+m-2} = \frac{\bar{X} - \bar{Y}}{\sqrt{s_p^2\left(\frac{1}{n} + \frac{1}{m}\right)}}$$ $$95\%\text{ CI of } (\mu_1 - \mu_2) = (\bar{X} - \bar{Y}) \pm t_{n+m-2, \, 0.975} \cdot \sqrt{s_p^2\left(\frac{1}{n} + \frac{1}{m}\right)}$$
    หมายเหตุ: หากทราบ Population variance ($\sigma_x^2, \sigma_y^2$) จึงใช้ Z-test: $Z = \frac{\bar{X} - \bar{Y}}{\sqrt{\sigma_x^2/n + \sigma_y^2/m}}$ (ในชีวิตจริงแทบไม่ทราบ จึงใช้ t-test)

1.2 Continuous Paired Data (L6-1)

ข้อมูลจับคู่ (Paired / Dependent data) เกิดได้จาก 3 รูปแบบ: (1) Before–After ในผู้ป่วยคนเดียวกัน, (2) Cross-over design, (3) Matched pairs design หลักการคือยุบ 2 ค่าเป็น 1 ตัวแปรคือ ผลต่าง $\Delta_i = X_{\text{after}} - X_{\text{before}}$ แล้วทดสอบแบบ 1-sample กับ 0 ($H_0: \mu_\Delta = 0$):

$$t_{df = n-1} = \frac{\bar{\Delta} - 0}{s_\Delta / \sqrt{n}}$$
WORKED EXAMPLE จากสไลด์ L6-1

ตัวอย่าง: คะแนนสอบ Diagnostic Test ของนักศึกษา 20 คน ก่อนและหลังเรียน Module

ได้ค่าเฉลี่ยผลต่าง $\bar{\Delta} = 2.05$, ส่วนเบี่ยงเบนมาตรฐานของผลต่าง $s_\Delta = 2.837$, $n = 20$:

• $SE(\bar{\Delta}) = \frac{2.837}{\sqrt{20}} = 0.634$  →  $t = \frac{2.05}{0.634} = \mathbf{3.231}$ ที่ $df = 20 - 1 = 19$  →  $p = \mathbf{0.004} < 0.05$ → Reject $H_0$ สรุปว่าหลักสูตรช่วยเพิ่มคะแนนอย่างมีนัยสำคัญ

1.3 Models Other Than Normal: Binomial, Poisson & Sign Test (L6-2)

Normal Distribution

ใช้กับ Continuous data (น้ำหนัก, BP, HbA1c)

พารามิเตอร์: Mean ($\mu$), Variance ($\sigma^2$)

Binomial Distribution

ใช้กับ Binary / Dichotomous data (ผลรวมของ Bernoulli($p$) อิสระ $n$ ครั้ง)

$$P(Y=i) = \binom{n}{i} p^i (1-p)^{n-i}$$
$E(Y) = np$, $\text{Var}(Y) = np(1-p)$
Bernoulli เดี่ยว: $E(X)=p, \text{Var}(X)=p(1-p)$ (สูงสุดเมื่อ $p=0.5$ ได้ $\text{Var}=1/4$)

Poisson Distribution

ใช้กับ Count data (จำนวนเหตุการณ์ต่อหน่วยเวลา/พื้นที่ เช่น จำนวนอุบัติเหตุต่อเดือน)

คุณสมบัติเด่น (ออกสอบบ่อย!):
$$\text{Mean} = E(Y) = \lambda = \text{Var}(Y)$$
เมื่อ $\lambda$ ใหญ่ จะประมาณด้วย Normal ได้

1.4 Nonparametric Tests: Sign Test, Wilcoxon Signed-Rank & Mann-Whitney U (L6-2 + 2025 Nonparametric)

  • Sign Test (signtest): ดูเฉพาะ เครื่องหมาย (+ / −) ของผลต่าง $\Delta_i$ โดย ไม่สนใจขนาดตัวเลข! ภายใต้ $H_0: \text{Median}(\Delta_i) = 0 \iff P(+) = 0.5$, จำนวนเครื่องหมายบวก $Y \sim \text{Binomial}(n, 0.5)$ (Power ต่ำกว่า Wilcoxon เพราะทิ้งข้อมูลขนาดไป)
  • Wilcoxon Signed-Rank Test (signrank): ใช้กับ 2 กลุ่มจับคู่ (เบ้/Ordinal) ขั้นตอน: (1) หาผลต่าง $d_i$, (2) จัดอันดับ $|d_i|$ โดยไม่คิดเครื่องหมาย (ตัด $d_i=0$ ทิ้ง), (3) รวมอันดับฝั่งบวก $T^+$ และฝั่งลบ $T^-$, (4) หา $T = \min(T^+, T^-)$
  • Mann-Whitney U / Wilcoxon Rank-Sum Test (ranksum): ใช้กับ 2 กลุ่มอิสระ (เบ้/Ordinal) นำข้อมูลทั้ง 2 กลุ่มมารวมกันแล้วเรียงลำดับ (Rank) เพื่อดูว่า Rank sum ต่างกันหรือไม่
WORKED EXAMPLE จากสไลด์ Nonparametric

ตัวอย่าง Saliva Cotinine (nmol/L) ที่ 12 ชม. vs 24 ชม. ในอาสาสมัคร 10 คน

คำสั่ง signrank After24 = After12 ได้ผล: positive = 2 (sum ranks = 4), negative = 8 (sum ranks = 51), zero = 0 → $T = \min(4, 51) = 4$, $z = -2.395$, Prob > |z| = 0.0166 < 0.05 → ระดับ Cotinine ลดลงอย่างมีนัยสำคัญจาก 12 ชม. ไป 24 ชม.

2.1 Pearson's Chi-Square, Cochran's Rule & Fisher's Exact (L9)

$$\chi^2 = \sum \frac{(O - E)^2}{E}, \qquad E_{ij} = \frac{\text{Row Total}_i \times \text{Col Total}_j}{N}, \qquad df = (r-1)(c-1)$$
📌 กฎของ Cochran (Cochran's Rule — ออกสอบประจำ!):
  • ตาราง $R \times C$ ทั่วไป: (1) ห้ามมีช่องใดมี $E < 1$ และ (2) จำนวนช่องที่มี $E \ge 5$ ต้อง มากกว่า 80% ของช่องทั้งหมด (ถ้าผิดข้อใดข้อหนึ่ง → ใช้ Fisher's exact)
  • ตาราง $2 \times 2$ โดยเฉพาะ:
    1) ถ้า $n \le 20$ → ใช้ Fisher's exact test เสมอ
    2) ถ้า $20 < n \le 40$ → ถ้ามีช่อง $E < 5$ ใช้ Fisher's exact; ถ้าทุกช่อง $E \ge 5$ ใช้ Chi-square (หรือ Yates' continuity correction)
    3) ถ้า $n > 40$ → ใช้ Pearson's $\chi^2$ (หรือ Yates' continuity correction: $\chi^2_{\text{Yates}} = \frac{n(|ad-bc| - n/2)^2}{(a+b)(c+d)(a+c)(b+d)}$)
  • ข้อจำกัดสำคัญ (สไลด์ P20): Chi-square บอกได้แค่ว่ามี Association หรือไม่ แต่ Association $\neq$ Causation และ บอกทิศทางไม่ได้ (ต้องคำนวณสัดส่วน %, PR, RR, OR เพิ่ม!)

2.2 Matched/Paired Binary Data & Crossover RCT (L10)

การวิเคราะห์ Matched Case-Control หรือ Crossover RCT (เช่น CPAP vs MAS ในสไลด์ L10) หรือ Pre–Post Binary: ห้ามเอาไปวิเคราะห์แบบ Unmatched 2×2 ปกติเด็ดขาด! ต้องจัดตาราง 1 คู่ = 1 หน่วย ($N$ pairs):

Crossover RCT (2-Treatment, 2-Period)

  • ข้อดี (Advantages): ผู้ป่วยเป็น Control ของตัวเอง → ลด Confounding, Paired analysis เพิ่ม Statistical Power, ใช้จำนวนคนน้อยกว่า
  • ข้อเสีย (Disadvantages): Carryover effect (ฤทธิ์ยาเดิมค้าง ต้องมี Washout period!), Period effect, Drop-outs กระทบมาก, ใช้ได้เฉพาะโรคเรื้อรังคงที่ (ไม่หายขาด)

McNemar's Test & Matched OR

ดูเฉพาะ Discordant pairs ($b, c$) (คู่ที่ผล 2 ฝั่งต่างกัน):
ภายใต้ $H_0: b = c$ (หรือ $b \sim \text{Binomial}(b+c, 0.5)$)

$$\chi^2 = \frac{(b-c)^2}{b+c}, \quad \chi^2_{\text{corr}} = \frac{(|b-c|-1)^2}{b+c}, \quad \text{OR}_{\text{matched}} = \frac{b}{c}$$

ถ้า $b+c < 25$ (หรือ $b+c$ น้อย) → ใช้ Exact McNemar p-value (Binomial tail)

3.1 หลักการ & โครงสร้างตาราง One-Way ANOVA (F-Table Anatomy)

วัตถุประสงค์ 2 ข้อของ ANOVA (สไลด์ L11 P21): (1) ทดสอบสมมติฐานเกี่ยวกับค่าเฉลี่ยประชากรตั้งแต่ 3 กลุ่มขึ้นไป ($H_0: \mu_1 = \mu_2 = \dots = \mu_k$ vs $H_a:$ มีอย่างน้อย 1 คู่ที่ $\mu_i \neq \mu_j$) และ (2) ประมาณค่าและทดสอบความแปรปรวนประชากร

Source of Variation Sum of Squares (SS) df Mean Square (MS) F-statistic
Between groups (Model / Treatment) $SS_B = \sum_{i=1}^{k} n_i (\bar{y}_i - \bar{y})^2$ $k - 1$ $MS_B = \frac{SS_B}{k - 1}$ $$F = \frac{MS_B}{MS_W}$$
Within groups (Error / Residual) $SS_W = \sum_{i=1}^{k} \sum_{j=1}^{n_i} (y_{ij} - \bar{y}_i)^2$ $N - k$ $MS_W = \frac{SS_W}{N - k}$
Total $SS_T = SS_B + SS_W$ $N - 1$ $MS_T = \frac{SS_T}{N - 1}$ —

ทำไมค่า F เบ้ขวาเสมอ & ความสัมพันธ์ $F = t^2$

  • $F \ge 0$ เสมอ (ติดลบไม่ได้): เพราะ $MS_B$ และ $MS_W$ มาจากผลรวมกำลังสอง
  • ใต้ $H_0$: ความแปรปรวนระหว่างกลุ่ม $\approx$ ในกลุ่ม $\implies F \approx 1$; เมื่อกลุ่มต่างกันมาก $F \gg 1$ พุ่งไปทางขวา → Rejection region อยู่หางขวาเท่านั้น
  • กรณี 2 กลุ่ม: One-way ANOVA ให้ค่า $F = t^2$ และ $p$-value เท่ากับ Independent t-test (two-tailed) เป๊ะ!

ลำดับความเข้มงวดของ Post-hoc (สไลด์ L11 P40)

เมื่อ ANOVA ซิก ($p < 0.05$) ต้องทำ Post-hoc เพื่อคุม Family-wise Type I error ($1 - (1-\alpha)^c$, โดย $c = \frac{k(k-1)}{2}$ คู่):

  • เข้มงวดที่สุด (Most conservative): Bonferroni ($\alpha^* = \alpha / c$) → โอกาส False positive ต่ำสุด (เช่น 4 กลุ่ม $\to 6$ คู่ $\to \alpha^* = 0.05/6 = 0.0083$)
  • รองลงมา: Scheffé → Tukey (HSD) → Duncan
  • เข้มงวดน้อยที่สุด (Least conservative): Fisher's LSD

4.1 องค์ประกอบ 4 ตัวของ Sample Size & ความหมาย Type I / II Error

Type I Error ($\alpha$), Type II Error ($\beta$) & Power ($1-\beta$)

  • Type I Error ($\alpha$ — False Positive): ปฏิเสธ $H_0$ ทั้งที่ $H_0$ เป็นจริง (นิยมตั้ง $\alpha = 0.05$)
  • Type II Error ($\beta$ — False Negative): ไม่ปฏิเสธ $H_0$ ทั้งที่ $H_0$ เป็นเท็จ (นิยมตั้ง $\beta = 0.20$ หรือ $0.10$)
  • Power ($1 - \beta$): ความน่าจะเป็นที่จะปฏิเสธ $H_0$ ได้อย่างถูกต้องเมื่อ $H_0$ เป็นเท็จ (นิยม 80%–90%)

ตารางค่า $Z$ ที่ต้องจำเข้าห้องสอบ

  • Two-sided $\alpha = 0.05 \implies \mathbf{Z_{1-\alpha/2} = 1.96}$
  • Two-sided $\alpha = 0.01 \implies \mathbf{Z_{1-\alpha/2} = 2.576}$
  • Power $80\%$ ($\beta = 0.20$) $\implies \mathbf{Z_{1-\beta} = 0.84}$
  • Power $90\%$ ($\beta = 0.10$) $\implies \mathbf{Z_{1-\beta} = 1.28}$
  • กฎเหล็ก: คำนวณได้ทศนิยมเท่าไหร่ ปัดขึ้น (Round UP) เสมอ!

5.1 Correlation vs. Regression & Pearson ($r$) vs. Spearman ($\rho$)

ความต่างระหว่าง Correlation กับ Regression

  • Correlation: วัด ความแรงและทิศทาง ของความสัมพันธ์เชิงเส้นระหว่างตัวแปร 2 ตัว ($r_{xy} = r_{yx}$ สลับแกนได้, ไม่มีหน่วย)
  • Regression: สร้างสมการ ทำนาย ค่าตัวแปรตาม $Y$ จากตัวแปรต้น $X$ ด้วยวิธี Ordinary Least Squares (OLS) (สลับ $X, Y$ ไม่ได้, ค่าความชัน $\beta$ มีหน่วย!)
  • จำให้แม่น: $r = -0.82$ แปลว่า Strong negative linear association แต่ ห้ามสรุปว่า X ทำให้เกิด Y (Association $\neq$ Causation) และ $R^2 = (-0.82)^2 = 0.6724$ (อธิบายได้ 67.2% ไม่ใช่ 82%!)

เกณฑ์ขนาด $|r|$ & การเลือกใช้

  • Pearson ($r$): Continuous ทั้งคู่, เส้นตรง, ปกติ, ไม่มี Outlier
  • Spearman ($\rho$): ข้อมูลเบ้, มี Outlier, หรือเป็น Ordinal
  • เกณฑ์ $|r|$: $0.10-0.29$ ต่ำ | $0.30-0.49$ ปานกลาง | $0.50-0.69$ สูง | $0.70-0.89$ สูงมาก | $\ge 0.90$ เกือบสมบูรณ์
  • Variation Decomposition (L14 P13):
    $SS_{\text{Total}} = SS_{\text{Model (Explained)}} + SS_{\text{Residual (Unexplained)}}$
    $$R^2 = \frac{SS_{\text{Model}}}{SS_{\text{Total}}} = 1 - \frac{SS_{\text{Residual}}}{SS_{\text{Total}}}$$

5.2 Multiple Linear Regression, Dummy Coding & Stepwise Selection (L14)

  • สมการทั่วไป: $Y = \beta_0 + \beta_1 X_1 + \beta_2 X_2 + \dots + \beta_p X_p + \varepsilon$
  • Dummy (Indicator) Variables: ตัวแปรเชิงกลุ่มมี $k$ กลุ่ม ต้องสร้าง $k - 1$ ตัวแปรดัมมี่ (เช่น 5 ภูมิภาค $\to 4$ dummy; 3 เชื้อชาติ $\to 2$ dummy) โดยเว้น 1 กลุ่มเป็น Reference
  • การตั้งสมมติฐานในสมการ Regression (ตัวอย่าง race 3 กลุ่ม):
    • Overall test (F-test): $H_0: \beta_1 = \beta_2 = 0$ vs $H_a:$ มีอย่างน้อยหนึ่งค่า $\beta_j \neq 0$
    • Individual test (t-test): $H_0: \beta_1 = 0$ vs $H_a: \beta_1 \neq 0$ (เทียบ Black กับ White)
  • Adjusted $R^2$: แก้ปัญหาที่ $R^2$ ปกติเพิ่มขึ้นเสมอเมื่อยัดตัวแปรเพิ่มเข้าไป โดยลงโทษตามจำนวนตัวแปรต้น — ใช้ Adj $R^2$ เปรียบเทียบโมเดล
  • Stepwise Criteria (สไลด์ L14 P37): เกณฑ์มาตรฐานมักใช้ Probability-of-F-to-enter $\le 0.05$ และ Probability-of-F-to-remove $\ge 0.10$
  • 4 Assumptions (L-I-N-E) + Multicollinearity: (1) Linearity, (2) Independence (ห้ามวัดซ้ำคนเดิมใน OLS ธรรมดา), (3) Normality of residuals (swilk r), (4) Equal variance / Homoscedasticity (rvfplot กราฟ residuals vs fitted values และ estat hettest), และ (5) No Multicollinearity (vif < 10)

6.1 หลักการ, สมการ Logit, การคำนวณ AOR และ Predicted Probability ($\hat{P}$)

4 วัตถุประสงค์หลักของ Multivariable Model (สไลด์ P23): (1) หาปัจจัยพยากรณ์โรคโดยควบคุมตัวแปรกวน (Confounders), (2) ปรับความแตกต่างของลักษณะพื้นฐาน (Baseline adjustment), (3) พยากรณ์โรค (Prognostic model), และ (4) ช่วยวินิจฉัยโรค (Diagnostic model)

$$\text{logit}(P) = \ln\!\left(\frac{P}{1 - P}\right) = \beta_0 + \beta_1 X_1 + \beta_2 X_2 + \dots + \beta_k X_k = z$$ $$\text{AOR (ต่อ 1 หน่วย)} = e^{\beta}, \qquad \text{AOR (เมื่อเพิ่ม } \Delta X \text{ หน่วย)} = e^{\beta \times \Delta X}, \qquad \hat{P} = \frac{1}{1 + e^{-z}} = \frac{e^z}{1 + e^z}$$

logit vs. logistic vs. reg (ห้ามสับสน!)

  • reg: Linear Regression สำหรับ Outcome Continuous
  • logit: Logistic Regression สำหรับ Outcome Binary (0/1) — แสดงผลเป็น Coef ($\beta$ = log-odds) ใช้เขียนสมการ & คำนวณ $z$
  • logistic: Logistic Regression ตัวเดียวกับ logit แต่แสดงผลเป็น Odds Ratio ($e^\beta$) ทันที!

• estat hettest: ทดสอบ $H_0:$ ความแปรปรวนของความคลาดเคลื่อนคงที่ (Constant variance / Homoscedasticity) ได้ $p = 0.3594 \ge 0.05$ → ยอมรับ $H_0$ ผ่านเกณฑ์ Homoscedasticity
• swilk r: ทดสอบ $H_0:$ ค่าความคลาดเคลื่อน (Residuals $r$) แจกแจงแบบปกติ ได้ $p = 0.3103 \ge 0.05$ → ยอมรับ $H_0$ ผ่านเกณฑ์ Normality of residuals
11.3) แปลผล estat gof, group(10) (Hosmer-Lemeshow Goodness-of-Fit):
• ทดสอบ $H_0:$ ค่าที่สังเกตได้จริง (Observed) ไม่แตกต่างจากค่าที่คาดการณ์จากโมเดล (Expected) (คือโมเดลมีความเหมาะสม/ฟิตดี)
• ได้ค่า $\chi^2(8) = 6.28, \mathbf{p = 0.6159 \ge 0.05}$ → ไม่ปฏิเสธ $H_0$ สรุปว่า โมเดล Logistic Regression นี้มีความเหมาะสมกับข้อมูลดี (Good fit)

คำถาม:
12.1) ในเรื่องที่ 1 ทำไมเมื่อกำหนด $p_1 = 0.35$ และ rrisk(0.5) โปรแกรมจึงคำนวณ $p_2 = 0.1750$ ออกมา? และต้องใช้กลุ่มตัวอย่างกลุ่มละกี่คน?
12.2) ในเรื่องที่ 2 ทำไมเมื่อกำหนดสัดส่วนการได้รับปัจจัยเสี่ยงในกลุ่ม Control ($p_1 = 0.30$) และ oratio(3) โปรแกรมจึงได้สัดส่วนในกลุ่ม Case ($p_2 = 0.5625$)? จงแสดงวิธีคำนวณ
12.3) หากในเรื่องที่ 1 คาดว่าจะมีผู้ติดตามไม่ครบ (Loss to follow-up / Drop-out) ร้อยละ 15% จะต้องเก็บตัวอย่างจริงกลุ่มละกี่คน และรวมทั้งหมดกี่คน?

✅ เฉลยละเอียด:
12.1) เรื่องที่ 1 (Cohort Study):
• จากนิยาม $\text{RR} = \frac{p_2}{p_1} \implies p_2 = \text{RR} \times p_1 = 0.50 \times 0.35 = \mathbf{0.1750}$ ($17.5\%$)
• ต้องใช้กลุ่มตัวอย่าง กลุ่มละ 131 คน (รวม 2 กลุ่ม $= 262$ คน) เพื่อให้มีอำนาจการทดสอบ (Power) 90% ที่ $\alpha = 0.05$
12.2) เรื่องที่ 2 (Case-Control Study):
• จากสูตรความสัมพันธ์ระหว่าง Odds กับ Proportion: $\text{Odds}_{\text{control}} = \frac{p_{\text{ctrl}}}{1 - p_{\text{ctrl}}} = \frac{0.30}{0.70}$
• เมื่อ $\text{OR} = 3 \implies \text{Odds}_{\text{case}} = 3 \times \frac{0.30}{0.70} = \frac{0.90}{0.70}$
• แปลงกลับเป็นสัดส่วนในกลุ่ม Case: $p_{\text{case}} = \frac{\text{Odds}}{1 + \text{Odds}} = \frac{0.90/0.70}{1 + 0.90/0.70} = \frac{0.90}{1.60} = \mathbf{0.5625}$ ($56.25\%$)
• ได้ขนาดตัวอย่างกลุ่มละ 74 คน (Case 74 คน, Control 74 คน รวม 148 คน)
12.3) การปรับเผื่อ Loss to follow-up 15% ($r = 0.15$) ในเรื่องที่ 1:
• ใช้สูตรหารด้วย $(1 - r)$: $n_{\text{per group}} = \frac{131}{1 - 0.15} = \frac{131}{0.85} = 154.12 \to$ ปัดขึ้นเป็น กลุ่มละ 155 คน (รวมทั้งหมด $155 \times 2 = \mathbf{310\text{ คน}}$)
